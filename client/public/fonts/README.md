# Elections font asset

`Inter-4.1-Variable.woff2` is the Roman variable webfont from the official Inter 4.1 release. It is used only in the Elections feed and supplies weights 100–900. The file is distributed under SIL Open Font License 1.1; the complete license is in `OFL-1.1.txt`.

Source: https://github.com/rsms/inter/releases/tag/v4.1

The UI uses the platform `system-ui`, `-apple-system`, Segoe UI, and sans-serif stack as fallbacks if the bundled font cannot load. It does not rely on an unbundled local Inter copy. The font is delivered locally, so Elections typography does not depend on a third-party font request.
